Gimnasio Digital UTTEC

Aplicación web y móvil para la gestión del gimnasio universitario

Descripción del proyecto

El sistema permite reservar clases, consultar disponibilidad y gestionar el acceso al gimnasio usando matrícula y códigos QR.

Objetivo general

Desarrollar una plataforma web/móvil para mejorar la experiencia y control del gimnasio institucional.
